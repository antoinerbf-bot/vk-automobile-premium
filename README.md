# VK Automobile — site vitrine premium

Site vitrine responsive en HTML autonome (CSS et JavaScript intégrés dans `index.html`), prêt à être déployé sur Vercel comme projet statique.

## Déploiement Vercel
- Importer ce dépôt GitHub dans Vercel.
- Framework Preset : **Other**.
- Build Command : laisser vide.
- Output Directory : `.`.
- Deploy.

## À vérifier avant publication
- Les visuels automobiles sont des images Unsplash illustratives.
- Les modèles de véhicules présentés sont des exemples de mise en page, pas des annonces de stock confirmées.
- Le formulaire prépare un email via l'application de messagerie du visiteur; il n'enregistre ni ne transmet les données à un serveur.
- Vérifier les coordonnées et textes avec VK Automobile avant mise en production.
